# 🧱 BLOC 2 : L’ENTREPRISE FICTIVE - NOVAFOOD GLOBAL

# 🏢 **NOVAFOOD GLOBAL**

Elle sert de **terrain d’entraînement professionnel** pour l’ensemble des cas pratiques du dépôt.

---

## 🌍 1. Présence géographique

### 🏭 **4 Usines de production**
- 🇫🇷 **France (Lyon)** : plats préparés & produits frais  
- 🇲🇦 **Maroc (Casablanca)** : épicerie & produits secs  
- 🇧🇷 **Brésil (São Paulo)** : boissons nutritionnelles  
- 🇻🇳 **Vietnam (Hô Chi Minh)** : snacks & produits instantanés  

### 📦 **3 Hubs logistiques internationaux**
- 🇧🇪 **Belgique (Anvers)** : hub Europe & Middle East  
- 🇰🇪 **Kenya (Nairobi)** : hub Afrique de l’Est  
- 🇲🇾 **Malaisie (Kuala Lumpur)** : hub Asie–Pacifique  

### 🌐 **Distribution dans 18 pays**
Europe, Afrique, Amérique du Sud, Asie du Sud-Est, Middle East.

NOVAFOOD reproduit la **complexité réelle** d’un FMCG mondial :  
zones de marché, fluctuations saisonnières, effets météo, hétérogénéité culturelle, fiscalité, promotions, et capacités industrielles variables.

---

### 📦 **+32 000 SKUs actifs**

- **FreshBite** : snacks, biscuits & barres énergétiques

Chaque marque possède des milliers de déclinaisons (formats, saveurs, grammages, packaging).

- Hypermarchés, supermarchés, convenience stores  
- Promotions, display en rayon, price ladders  
- Volatilité forte en période promo  

### 📦 **E-commerce**
- Plateformes e-retailers  
- Quick-commerce 15–30 minutes  
- Forte explosivité de la demande (effet météo, buzz social)  

### 🍽️ **Food Service / B2B**
- Hôtels, restaurants, cantines  
- Contrats long terme & saisonnalité spécifique  

Chaque canal a des **patterns de demande distincts**, utilisés dans les exercices du dépôt.

Dans PowerShell / Terminal :

cd "C:\Users\Dell\Documents\TEST_Demand_Planner"

cd FORECASTLAB
code .


VS Code s’ouvre automatiquement dans le dépôt.

🔧 3. Organisation de ton travail

Chaque section du dépôt correspond à une compétence métier.
Chaque cas pratique est une unité de travail isolée.

Après avoir ouvert FORECASTLAB dans VS Code :

Choisis une section :
docs/01_Fundamentals_SupplyChain/

Choisis un cas pratique :
S1_2_MDM_Cleanup_2500SKU.md

Ouvre le dataset associé dans :
datasets/novfood_case_studies/

Lance ton environnement :

Excel si le cas est orienté Power Query / DAX

Python si le cas est orienté ARIMA / ML / simulation

Power BI pour les dashboards

🔧 4. Workflow professionnel en 7 étapes

Ce workflow suit les mêmes étapes que dans un projet Data Supply Chain réel.

🟦 Étape 1 : Créer une nouvelle branche de travail

Tu ne travailles jamais directement sur main.

git checkout -b feature/S1_2_MDM_Cleanup

🟦 Étape 2 : Exécuter le cas pratique

Tu avances :

lecture du fichier .md

ouverture du dataset

nettoyage, modèles

construction des graphiques

écriture de la recommandation business

ajout des outputs dans outputs/

🟦 Étape 3 : Documenter ton travail

Dans VS Code, mets à jour :

docs/01_Fundamentals_SupplyChain/S1_2_MDM_Cleanup_2500SKU.md


Avec :

ta méthodologie

ton pipeline PQ / SQL / Python

les décisions prises

les insights

les KPIs

les limites & améliorations

⚠️ Les recruteurs adorent la partie “insights + limites + next steps”.

🟦 Étape 4 : Commit propre

Chaque commit doit être :

clair

professionnel

traçable

Exemple :

git add .
git commit -m "S1.2: MDM cleanup — ajout dataset + analyse + recommandations"


Jamais de commit flou ou vide.

🟦 Étape 5 : Push sur GitHub
git push origin feature/S1_2_MDM_Cleanup

🟦 Étape 6 : Pull Request (PR)

Depuis GitHub :
feature/S1_2_MDM_Cleanup → main

Dans la PR, ajoute :

description du cas

méthodes utilisées

éléments techniques

screenshots (Excel, Python, Power BI)

KPIs obtenus

Cette bonne pratique montre que tu sais travailler en équipe.

🟦 Étape 7 : Merge & archivage

Après relecture :

git checkout main
git pull
git merge feature/S1_2_MDM_Cleanup


Ta progression est proprement intégrée.

🔧 5. Mise à jour continue du dépôt

FORECASTLAB est un projet vivant.
Tu peux y ajouter :

- de nouveaux cas pratiques

- de nouvelles features Python

- de nouveaux dashboards

- de nouveaux générateurs de datasets

Chaque ajout doit suivre :

docs/xx/
datasets/
excel_templates/
notebooks/
systems/


Et être intégré via une branche + PR propre.

🔧 6. Utilisation multi-outils (workflow hybride)

FORECASTLAB permet un workflow Excel ↔ Power Query ↔ SQL ↔ Python ↔ Power BI.

Exemple workflow complet :

- Nettoyage + structuration → Power Query

- Modélisation KPIs → DAX

- Forecast ARIMA / ML → Python

- Dashboard Forecast vs Actual → Power BI

- Export final → Excel

- Documentation → Markdown dans VS Code

Versioning → Git

C’est un workflow professionnel, exactement utilisé dans :

Demand Planning

Data Analytics

Supply Chain Control Tower
